# 雅思词汇真经 · 本地单词卡

把刘洪波《雅思词汇真经》整理成一个可以离线使用的背单词小网站：先回忆单词，再展开音标、释义和例句，用掌握标记和生词本记录自己的学习进度。

**22 个章节 · 3,674 个词条 · 可复制文字 · 无需服务器 · 学习记录本地保存**

## 资料与内容

- 按原书章节及词条顺序整理，保留音标、释义、英文例句、中文译文、搭配、记忆说明及插图。
- 词条正文以可选中、可复制的文字展示；原书插图仍使用图片。
- 每条词卡都有「对照原书」，可展开对应扫描内容。解压原书 PDF 后，还可以点击「查看原书」跳到对应页。
- 不同章节出现的同名单词分别保留、分别记录进度。
- 文字经过 OCR 转写、双文本逐行比对和疑点回看。普通正文并非每个字都独立目视复核，不能保证零识别错误；详细范围见 [校对记录](校对记录.txt)。遇到疑问请以原书扫描内容为准。

原书 PDF 以无损 ZIP 压缩包保存在 [资料](资料/) 中。解压得到的 PDF 与本地原文件字节一致，没有删页或重新压缩书页。

## 小网站可以做什么

| 功能 | 用法 |
| --- | --- |
| 按章节学习 | 左侧选择章节，也可以查看全书词条 |
| 回忆后揭晓 | 卡片先显示单词，点击「查看解释」平滑展开正文 |
| 掌握标记 | 点击右上角 ✓ 标记掌握，再点一次取消 |
| 生词本 | 点击 ! 收藏不熟悉的词；右侧可查找、移除和集中复习 |
| 今日已背 | 当天查看过解释的不同词条数；同一词条一天只计一次 |
| 搜索与筛选 | 按单词查找，筛选全部、未掌握、已掌握；每页 24 张词卡 |
| 复制与核对 | 选中文字或点击「复制文字」，也可展开原书扫描内容核对 |
| 进度备份 | 导出 JSON 文件；换设备后导入，合并学习记录 |
| 自适应排版 | 随可用宽度显示一至三列，手机上通过顶部按钮打开目录和生词本 |

掌握和生词状态互斥：标记掌握会移出生词本，加入生词本会取消掌握标记。网站没有账号、云同步、广告或统计服务。

## 下载

1. 在本仓库点击绿色 **Code → Download ZIP**，下载后完整解压。也可以使用 GitHub Desktop 克隆仓库。
2. 需要阅读整本原书时，再把 `资料/雅思词汇真经-原书.zip` 中的 PDF 解压到项目根目录，与 `开始背单词.html` 放在同一层，保持 PDF 文件名不变。
3. 保留整个 `dist` 文件夹。不要只下载 GitHub 页面上的一个 HTML 文件，也不要直接在压缩包里打开网页。

只背单词时不必解压 PDF：文字、插图和词条原图已经包含在网站中。

## Windows 电脑本地使用

1. 双击 `开始背单词.html`，选择新版 Microsoft Edge 或 Google Chrome 打开；也可以直接打开 `dist/index.html`。
2. 选择章节，点击词卡的「查看解释」，开始学习。
3. 下次从同一位置、用同一个浏览器打开，继续学习。无需安装 Node.js、Python，也无需启动服务器。
4. 左下角「导出进度」可保存备份；换电脑或浏览器时，点击「导入进度」选择备份 JSON。

## Android 安卓本地使用

1. 下载并解压完整仓库，放在手机上一个固定文件夹，例如 `Download/IELTS-Cards`。
2. 在文件管理器中找到 `dist/index.html`，选择支持本地 HTML 的浏览器打开。如果能正常显示目录和词卡，并能展开解释，即可学习。
3. 如果默认浏览器只显示源码、空白页或缺少样式，改用支持**整个文件夹、JavaScript 和 DOM Storage / localStorage** 的本地 HTML 阅读器，从阅读器内打开这个文件夹中的 `dist/index.html`。仅支持静态预览的阅读器不够。
4. 在所用阅读器中完成一次保存检查：标记一个词，退出并重新打开同一个文件，确认标记仍在；再试一次「导出进度」和「导入进度」。不同 Android 文件管理器和 WebView 对本地文件的处理不同。

可参考开发者提供的 [WebView 本地 HTML 阅读器](https://gilliardnascimento.itch.io/webview)：其功能说明包含本地文件访问、JavaScript 和 DOM 存储。这里提供选型参考，尚未对该阅读器做本项目的真机验收；也可使用满足上述条件的其他工具。阅读器安装好、文件下载完整后，背词过程无需联网。

## iOS / iPadOS 本地使用

本项目是静态网页，不是 App Store 应用。iPhone 的「文件」预览不应作为完整网页运行环境；请使用能运行 JavaScript、读取整个网站文件夹并持久保存 localStorage 的 HTML 阅读器。

1. 用 Safari 下载仓库 ZIP，在「文件」中解压，保存到「我的 iPhone」或「我的 iPad」的固定位置。
2. 安装合适的本地 HTML 阅读器。例如 [Sitecase](https://sitecase.io/en/) 的开发者说明支持离线 HTML/CSS/JavaScript 和整个网站文件夹；**打开整个文件夹属于其 Pro 功能，可能需要付费**，可用性以所在地区 App Store 为准。
3. 从阅读器的文件夹导入/打开功能选择完整项目文件夹，然后打开其中的 `dist/index.html`。需要使用「查看原书」时，先将 PDF 解压到项目根目录，再导入整个项目。
4. 后续从阅读器中打开同一份已导入项目，避免每次重新导入形成不同副本。
5. 先标记一个词，完全退出阅读器再打开，确认记录保留，并试用进度导出、导入。阅读器需要支持网页下载和文件选择；只有画面能打开不代表备份功能也能使用。

[Sitecase 的 App Store 开发者更新说明](https://apps.apple.com/us/app/html-viewer-sitecase/id6762896369)提到导入网站文件夹的 localStorage 持久保存，以及网页导出文件支持。以上操作路径依据开发者说明整理，**本项目尚未完成 Android、iPhone、iPad 真机测试**，不承诺所有浏览器或阅读器兼容。无需部署服务器，但手机端可能需要额外的阅读器。

## 学习进度与备份

- 记录保存在当前浏览器/阅读器的 `localStorage` 中，不会提交到 GitHub，也不会随代码自动同步。
- 不同设备、不同浏览器，以及不同文件位置的记录可能相互独立。更换设备前先导出，再在新设备导入。
- 导入会合并记录；同一词条的掌握/生词状态以导入的备份为准。
- 不要依赖隐私模式长期保存；清理浏览器数据、卸载阅读器、移动或重新导入项目后，应准备好进度备份。
- `file:` 页面下的 localStorage 行为没有统一保证，详见 [MDN 说明](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)。因此建议固定使用环境并定期导出。

  index.html                主页面
