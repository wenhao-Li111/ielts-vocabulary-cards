《雅思词汇真经》· Liu Hongbo 单词卡

电脑、安卓、苹果可直接打开网页版：https://wenhao-li111.github.io/ielts-vocabulary-cards/
Windows EXE、Android APK 的下载链接及完整步骤见 README.md。
Windows 版默认每 30 分钟显示一张常驻词卡，支持暂停和自定义间隔。关闭主窗口后留在托盘；从托盘退出后停止提醒。
三个版本分别在本机保存进度，换用新版本请先导出再导入。以下是原文件夹版的使用方法；手机使用网页版或 APK 无需额外阅读器。
从 GitHub 下载时，请完整解压仓库。需要阅读 PDF 时，将「资料/雅思词汇真经-原书.zip」中的 PDF 解压到本文件夹根目录，并保留原文件名。

使用方法
1. 双击本文件夹里的「开始背单词.html」，使用 Edge、Chrome 或其他现代浏览器打开。
2. 在左侧选择章节，点击单词卡上的「查看解释」展开原书内容。
3. 点击卡片右上角 ✓ 标记掌握；点击 ! 加入生词本。重复点击可取消。
4. 右侧生词本支持查找、单词复习和移除；也可以点击「复习生词本」集中学习。
5. 右上角「今日已背」统计当天查看过解释的不同词条，同一词条一天只计一次。
6. 左下角「导出进度」下载备份。更换浏览器或电脑后，用「导入进度」恢复。
7. 词卡会按实际可用宽度排成一至三列；窄屏通过顶部按钮打开章节目录和生词本。
8. 查看和收起解释时会平滑展开、折叠；设备开启「减少动态效果」时直接显示。

内容说明
全书 22 章、3,674 个词条，按原书顺序保留。
词条正文转换为可选中、可复制的文字，含音标、释义、例句、搭配和记忆解释；实际插图仍以图片保留。
释义、英文例句、中文译文及记忆说明分段排版，使用深灰和柔和灰绿色。
可选中文字复制，也可以点击「复制文字」复制整条内容。
「对照原书」展开对应扫描内容；原始词条图片不作修改。
文字已完成一轮覆盖全书的双文本逐行比对，回看全部词条音标、正文识别疑点及标点差异；具体范围见「校对记录.txt」。
原书上下叠写的弱读音标同时保留两个字符，仍可选中和复制。释义与例句以原书为依据，不引入其他词典的解释。
跨栏、跨页的原文已接续。不同章节的同名单词保留为不同词条。
单词标题通过正文、页脚词表、书末索引交叉核对；修正了 PDF 识别层的标题空格和误识别。
展开后的「查看原书」可打开原 PDF 的对应页。

保存说明
无需服务器，下载完整后学习无需联网。Windows 可直接用浏览器打开；手机可能需要额外安装 HTML 阅读器。记录只保存在当前浏览器或阅读器的本地存储。
请使用固定浏览器和文件位置。浏览器隐私模式、清理浏览器数据、移动文件或更换浏览器可能让原来的记录不可见。
建议定期导出进度；进度导入会合并记录，同一单词状态以备份为准。
不要单独移动 HTML 文件；请保持「dist」里的 HTML、JS、CSS 和 assets 文件夹完整。
整个文件夹可一起拷贝到其他电脑，用导出的 JSON 恢复进度。
