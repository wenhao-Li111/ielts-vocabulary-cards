# 原书资料

`雅思词汇真经-原书.zip` 是本项目所用原始 PDF 的无损 ZIP 压缩包。压缩包中的 PDF 与原文件字节一致，校验值见 `checksums.json`。

原 PDF 大于 GitHub 普通仓库的 100 MiB 单文件限制，因此以约 85 MiB 的 ZIP 保存；书页没有重新编码、删减或重排。

解压时将 PDF 放到项目根目录，与 `开始背单词.html` 同一层，保留压缩包内的原文件名。这样词卡上的「查看原书」链接可以找到 PDF。仅使用词卡文字和词条原图，不需要额外解压 PDF。

原书为刘洪波编著的《雅思词汇真经》。原书及派生文字、图片不适用网站代码的 MIT 许可，详见 [版权说明](../NOTICE.md)。
